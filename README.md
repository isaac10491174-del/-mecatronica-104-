## 📌 Sobre o Projeto

Este projeto aborda a aplicação prática da **Robótica em Ambientes Mecatrônicos**, explorando a integração sinérgica entre **engenharia mecânica, eletrônica, controle e computação** para o desenvolvimento de sistemas automatizados de alta precisão, repetibilidade e eficiência.

O objetivo é documentar a modelagem, o funcionamento e a implementação de módulos robóticos industriais, cobrindo desde o sensoriamento até o controle em malha fechada.

---

### 🔗 Relação Direta entre Mecatrônica e Robótica

A **mecatrônica** é a engenharia multidisciplinar que integra mecânica, eletrônica, teoria de controle e computação. A **robótica** representa a **aplicação máxima e tangível** dessa integração, resultando em sistemas autônomos ou semi-autônomos capazes de interagir fisicamente com o ambiente.
